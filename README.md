# 河川堤防 重力式パラペット設計計算書 Webアプリ

河川堤防に設置する重力式パラペットを対象に、設計者が発注者提出用の計算書ドラフトを作成するための、依存ライブラリ不要の Web アプリです。

## 対応範囲

- 台形断面、前面・背面勾配付き断面の寸法入力
- 河川管理施設等構造令を前提条件として計算書に明記
- 常時、地震時、異常時の荷重ケース切り替え
- 水平・鉛直震度法による地震時作用
- 試行くさび法相当の主働土圧、受働土圧、静水圧、揚圧力
- 転倒、滑動、偏心、合力作用位置、地盤支持力、極限支持力の照査
- OK/NG 判定、荷重・モーメント集計、改善案の表示
- 設計条件、断面諸元、荷重集計、モーメント集計、計算式・照査過程、判定一覧、改善案を含む計算書ドラフト
- 断面図付きの計算書ドラフトをブラウザ印刷で PDF 保存
- 案件名・検討日を含む条件のブラウザ内保存

> 注意: 初期版は計算書作成の下書き・検算補助を目的としたプロトタイプです。提出前には最新版の基準類、地盤調査結果、発注者協議条件、施工時条件で必ず照合してください。

## 使い方

このアプリは静的な HTML/JavaScript だけで動くため、**サーバーに接続できない場合は URL を開かず、ファイルとして `web/index.html` を直接ブラウザで開いてください**。

### サーバーなしで開く（推奨）

ファイルが見つからない場合に備えて、リポジトリ直下に **単体版** を用意しています。まずはこちらを開いてください。

```text
parapet_design_app.html
```

このファイルだけで画面・計算・PDF印刷まで動きます。

フォルダ構成のまま使う場合は、次の手順でも開けます。

1. ダウンロード/展開したフォルダを開きます。
2. `web` フォルダを開きます。
3. `index.html` をダブルクリックします。
4. ブラウザのアドレス欄が `file:///.../web/index.html` のようになっていれば成功です。`http://127.0.0.1:8000/...` ではありません。

リポジトリ直下の `index.html` を開いた場合は、`web/index.html` と単体版 `parapet_design_app.html` へのリンクを表示します。

### ローカルサーバーで開く（任意）

```bash
python -m http.server 8000 --bind 127.0.0.1
```

同じPCのブラウザで `http://127.0.0.1:8000/web/` を開き、Excel 風の入力シートに条件を入力して「計算する」を押してください。PDF は「計算書PDFを作成」からブラウザの印刷ダイアログで保存できます。出力される計算書ドラフトには、設計条件、断面諸元、材料・地盤定数、荷重集計、モーメント・接地圧集計、計算式・照査過程、判定一覧、改善案・留意事項を含みます。

別PC・社内LAN上の端末から接続する場合は、サーバー側で次のように起動し、ブラウザでは `http://<サーバーPCのIPアドレス>:8000/web/` を開いてください。

```bash
python -m http.server 8000 --bind 0.0.0.0
```

接続できない場合は、Python が起動しているか、ポート番号が違っていないか、ファイアウォールで 8000 番ポートが遮断されていないかを確認してください。ポートが使用中の場合は `python -m http.server 8001 --bind 127.0.0.1` のように別番号で起動できます。
